# rec/ — video explicativo

Este directorio contiene el video asciinema de **Tuboteca: tu catálogo de YouTube, en local** y el reproductor
que se usa en la página del proyecto.

- `tuboteca.cast`: grabación original (asciicast v2).
- `tuboteca.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 2:55. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
